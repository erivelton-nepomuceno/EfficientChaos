# Efficient Chaos

Chaotic maps and flows built from nothing but two-input AND, OR, XOR and NOT gates in n-bit fixed point, ranked by cost (gates per iteration L(n) and energy per output bit) and checked for fidelity: the 64-bit fixed-point logic circuit against float64 (baseline) and exact arithmetic, for 73 systems (119 rows: maps, and flows with Euler and RK4).

**Live page:** https://erivelton-nepomuceno.github.io/EfficientChaos/

The page is a single self-contained file (`index.html`): sortable columns, class, type and scheme filters, search, and a profile for every system with attractor plots, equations, parameters, the fidelity metrics and the original reference (with BibTeX).
